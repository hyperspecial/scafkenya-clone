# SCAFKENYA - Sickle Cell Awareness Foundation Kenya

A modern, responsive landing page for SCAFKENYA, a community health center dedicated to sickle cell awareness and support in Mombasa, Kenya.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Project Structure

```text
src/
├── app/
│   └── page.tsx           # Main entry point
├── components/
│   ├── layout/            # Global layout components (Navbar, Footer)
│   ├── sections/          # Individual page sections (Hero, About, etc.)
│   └── ui/                # Base UI components (shadcn/ui)
└── constants/
    └── images.ts          # External image assets
```

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
